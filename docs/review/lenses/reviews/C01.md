# C01 — Parent, birthday gift, ~$40, wants a Luffy card (new to One Piece)

**Reference first impression**
Collectr opens like a shop — Search, Shop, a cart icon — then dumps One Piece as Price high-to-low, so the first Luffys are $100,000 / $40,000 trophy and serial prints with SAMPLE watermarks and green % badges. Nothing on the first screen is a $40 birthday gift, and the price-range filter that would find one is marked PRO.

**Piecebook /belong first impression**
I land on a quiet paper “World” that asks how far I have read, defaults to Debut arc, and offers Story, People, Fruits, and The game — plus Gecko Moria’s birthday. There is no Luffy, no dollar, no card, and no box; it feels like a spoiler-safe wiki, not a place to pick a gift.

**Top 5 frictions**
1. High — `/belong` has no search, no seed prices, and no card or box. The URL I was sent to cannot start “a Luffy card” or a $40 box.
2. High — Sets leads with booster tiles at about $105–$125, all over budget. The $40-feasible products (starter-deck rows, including ST-08 Monkey.D.Luffy at $15.99) sit under that stack; a parent can bounce thinking everything is too expensive — the same sticker shock as Collectr.
3. High — Opening a set (OP-09) defaults the grid to Price · high to low, so chase prints lead. Facets are colour / type / cost / trait / owned — not a dollar budget — so I cannot ask for “under $40.”
4. Med — With nothing owned, the Sets tab replaces itself with Start (Collect / Play / World). Collect is “what you have”; World sends me back to `/belong`; none of the doors say find a card.
5. Med — “What you own,” Collection, Portfolio, and “0 / N cards in your collection” speak to a collector. People → “Find a name” can reach Luffy prints, but it is framed as fruit and debut chapter, not a gift price.

**3 that work**
- Every set tile prints a box seed price, so I can see in one glance that a booster box is not a $40 gift.
- ST-08 is named Monkey.D.Luffy at $15.99 (ST-10 and ST-13 also sit under $40) — a real Luffy product in budget, once I scroll to starter decks.
- Sets search (“Search cards, sets, artists”) plus the character page can list Luffy prints with a seed $ on each cell, on quiet paper, without SAMPLE chrome or a $300,000 lead.

**One trade**
Collectr puts Luffy in my face on the first screen and only the unbuyable ones; Piecebook can show a $16 Luffy deck and cheap singles, but only after I leave the story room I was sent to.

**One improvement**
Put the existing Sets search on `/belong` so typing Luffy lists prints with seed prices, cheapest first.
