# C03 — Pokémon shopper comparing to OP (new to One Piece)

**Reference first impression**
Collectr is the board I already know from Pokémon: Find a Product, One Piece ticked in the same category list as Pokémon, art grid, huge USD, green/red %, a + on every tile. Sorted Price high to low, the first glass is trophy / serial / manga prints from about $250,000 down, many stamped SAMPLE — so “like Pokémon?” reads as a chase ticker, not a pack or a box I would actually buy.

**Piecebook /belong first impression**
World is a reader desk: HOW FAR HAVE YOU READ stuck on Debut arc, then Story, People, Fruits, The game; On This Day names Gecko Moria’s birthday. There is no box art, no seed price, no card grid — nothing I can put next to a Scarlet & Violet box or a $4 pack — so I cannot tell from this page whether OP cards are like Pokémon.

**Top 5 frictions**
1. High — Reviewers land on `/belong`, which has no box price and no card grid. The job cannot start on the first Piecebook page.
2. High — The game’s first row is “What you own” / “Sets, the collection, what it is worth today.” I own nothing. That is a collection door. “Sets in order” is second.
3. Med — A first visit to Sets with nothing owned redirects to Start (Collect / Play / World). Another three doors before box tiles. “Just show me the sets” is the path I need, and it is the last ink on Start.
4. Med — Once I reach Sets, names are Romance Dawn, The New Emperor, OP-09, ST-14. I know booster box / ETB / tin / sleeved pack. I can see a box seed price, but I still do not know if I want a booster box or a starter deck.
5. Low — OP-09’s card grid also defaults Price · high to low, same as Collectr. Chase singles first. Better than $250k trophies (seed $ and week move in ink, star / own, no +), but still not “a normal card” sitting next to the box.

**3 that work**
1. Sets tiles: box art, set name, card count, box seed price — that is the Pokémon comparison (what a sealed box costs).
2. Start’s trust line: prices from TCGplayer, cards from Limitless, dates from Bandai — I already shop Pokémon on TCGplayer numbers.
3. OP-09: one-sentence set story, dates, the box as a product with a seed price, then a grid of named cards with seed $ and week move. I can see a Luffy and what it costs without SAMPLE watermarks.

**One trade**
Piecebook trades Collectr’s multi-TCG chrome (Pokémon in the same sidebar, sort-by-price chase, % badges, +) for a One Piece-only paper desk that starts at World. I lose both games on one screen; I gain boxes and singles that look like products, not a trophy ticker.

**One improvement**
On `/belong`, put the existing Sets tile facts — one English box’s art, name, card count, and seed price — on The game’s first row, so a Pokémon shopper sent to World can answer “what does a box cost” without leaving the page.
