# C04 — New adult, one iconic card, heard it is expensive (new to One Piece)

**Reference first impression**
Collectr opens like a shop — cart 0, Find a Product, Price high to low, Cards Only, One Piece — then the first glass is trophy and serial prints at $200,000 / $100,000 / $50,000, many stamped SAMPLE, each tile a + and a 0.00% badge. I came for one famous card and the site answers “yes, it is expensive” before I know who Kaido or Yamato is.

**Piecebook /belong first impression**
World is quiet paper: HOW FAR HAVE YOU READ stuck on Debut arc, then Story, People, Fruits, The game — titles and ranges, a print log, Gecko Moria’s birthday. There is no card, no seed price, no box; I cannot start “buy one iconic card” on the page I was sent to.

**Top 5 frictions**
1. High — `/belong` has no search, no card grid, and no seed $. The job cannot start here. “What you own” is the first game row, and I own nothing.
2. High — Sets is boxes. The first tile is Romance Dawn, Box · US $1,468.78. I said not a box, and the first number confirms the rumor.
3. High — OP-09 still leads with the box, then the card grid defaults to Price · high to low: Manga Art $5,500 / $2,699 chase. The $25.79 Roger and $1.17 Shanks exist only after a long scroll.
4. Med — I do not know a name to type in search, and nothing on World or Start says “one card.” People is fruit and debut chapter.
5. Med — A first visit to Sets with nothing owned redirects to Start. The only shopper exit is the last line, and it is still sets.

**3 that work**
- Quiet paper, unofficial line, seed dated from TCGplayer — I can read a number and go buy the card somewhere else. No cart, no +.
- Inside OP-09, each cell carries a seed $ and a week move. A $25.79 Gol.D.Roger and a $1.17 Shanks sit under the manga wall.
- Sets search is labeled for cards, not only boxes — a path to one print if I ever learn a name.

**One trade**
Collectr puts cards on the first screen and only the unbuyable ones; Piecebook can show a $26 Roger, but only after I leave World, skip a $1,468 box list, open a set, and scroll past $5,500.
