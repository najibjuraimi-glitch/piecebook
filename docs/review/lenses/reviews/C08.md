# C08 — Googled “buy one piece cards”, lost (new to One Piece)

**Reference first impression**
Collectr looks like the shop Google promised: Find a Product, Shop, a cart icon, a grid of cards with huge USD. The first cards are $200,000 trophies with SAMPLE stamps. I still do not know what to buy, only that someone is selling something I cannot afford.

**Piecebook home / Start first impression**
Piecebook does not look like a shop. Three doors: Collect, Play, World. The unofficial line is honest. Nothing says “buy.” I am less lost about whether this is a store, and more lost about where a first card lives.

**Top 5 frictions**
1. High — I searched for buy. Collect is ownership. Play is rules and decks. World is story. The word buy never appears, and the first card is not on Start.
2. High — Sets leads with $1000-class boxes. I asked for cards. The card grid is one set tap later, and that grid defaults Price · high to low.
3. Med — Search exists only after I reach Sets. Start has no field. I cannot type Luffy on the first page.
4. Med — Five tabs on a first phone visit (Sets, Collection, Decks, Portfolio, World) before I know which one holds a card I could pay for.
5. Low — How prices work is a trust line I need, but it sits under the doors as fine print.

**3 that work**
- Start says the site is unofficial and names TCGplayer / Limitless / Bandai — I know this is not a checkout.
- Sets search can take a name once I find it.
- Starter-deck rows are the first products that look like a normal first buy, if I scroll.

**One trade**
Look like a shop (Collectr) and scare me, vs look like a book (Piecebook) and hide the first payable card.

**One improvement**
Put the existing Sets search on Start, labelled “Find a card or a box,” so a lost Google visit can type a name before choosing a door.
