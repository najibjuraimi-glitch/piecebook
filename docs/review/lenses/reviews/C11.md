# C11 — Standard playset of a staple (plays One Piece)

**Reference first impression**
Collectr’s high-to-low tape is chase. I need four copies of a $2 staple. Price range is PRO. I will use search if I know the name.

**Piecebook home / Start first impression**
Start → Sets search. I can type the name. Cells show seed $. Playsets live on Collection after I own copies — “2 of 4 for a playset.” I do not own them yet, so the job is find-and-price, then buy elsewhere.

**Top 5 frictions**
1. High — A set page defaults Price · high to low. The staple is at the bottom.
2. Med — Playsets are an owned reading, not a shopping reading. I cannot see “you need 3 more” until I mark qty.
3. Med — Global search groups by set. A staple reprinted in PRB and a starter is several rows.
4. Med — Start Collect is “what you have.”
5. Low — No colour+name+cheap default.

**3 that work**
- Search by name or number. Facets are not PRO.
- Seed $ on the cell. I take it to a shop.
- Once owned, Playsets on Collection is the right noun.

**One trade**
Keep playsets as an owned tool vs inventing a “need 4” shop list.

**One improvement**
When I open a card from search, keep the seed $ at the top and say how many I already marked (qty already exists) so I know how many to buy elsewhere.
