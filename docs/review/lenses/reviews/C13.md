# C13 — Budget colour restock (plays One Piece)

**Reference first impression**
Collectr’s One Piece grid is Price high to low. I need cheap red or green playables. The first screen is six-figure trophies. Price range is in the sidebar and marked PRO. Colour is not how this tape is cut.

**Piecebook home / Start first impression**
Start → Sets. Search can read a colour word as a facet. That is closer to the job than Collectr’s first glass. The page still opens as boxes, oldest first.

**Top 5 frictions**
1. High — I have to know to type `red` (or open Colour) on Sets search. The first fold is booster tiles, not a colour restock.
2. High — Opening a set still defaults Price · high to low, so the cheap restock is at the bottom of OP-09 even after I picked a set.
3. Med — Facets are on search results, not on the set grid until I type. An empty set page is chase, not budget colour.
4. Med — Start’s Collect door is “what you have.” A restock is what I still need.
5. Low — S$ is only on Portfolio. I restock in the unit the shop uses.

**3 that work**
- Sets search already parses colour, type, cost, owned / missing. That is the restock language.
- Cells print seed $ in ink. A $0.16–$2 staple is readable once I get off the manga wall.
- No PRO gate on facets.

**One trade**
Keep set pages as Price · high to low (the shipped default) vs landing a colour search on Price · low to high for a restock.

**One improvement**
When Sets search has a colour facet, default those results to Price · low to high so the first red I see is a restock, not a manga.
