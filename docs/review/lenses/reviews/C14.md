# C14 — Buying a booster box to rip (plays One Piece)

**Reference first impression**
Collectr opens One Piece as Cards Only, Price high to low: SAMPLE-watermarked trophy and serial prints from about $200,000 down, with a + on each tile. The box I came to rip is one radio tap away (Sealed Only); the first screen is investor singles, not a current booster box.

**Piecebook /belong first impression**
World asked how far I have read and left Debut arc on. There is no box art, no seed price, and no OP-16 or OP-17 — The game door only promises sets in English order and what is coming next.

**Top 5 frictions**
1. High — Reviewers land on `/belong`. Cutoff chips, Story, People, Fruits, On This Day. No box price and no card grid. The job cannot start until I leave World.
2. High — Sets tiles are oldest EN first. The first product is Romance Dawn, Box · US $1,468.78. Current rip targets (OP-16, OP-17) sit after a long stack. Jump links go to coming soon and starter decks, not the latest released box.
3. Med — World’s The game door and “Sets in order” open the Timeline with no prices. “What you own” is framed as collection worth, not a box to rip.
4. Med — OP-09 set detail treats the box as a product then the grid is Price · high to low chase. Useful EV for this set; it is not a current box, the seed is dated, and the TCGPlayer URL is not a link.
5. Low — A first visit to `/` with nothing owned redirects to Start here. After booster tiles, 36 starter-deck rows are easy to mistake for the box I came to rip.

**3 that work**
1. Released set tiles show box art, EN SET · OP-xx, card count, and Box · US $ · as of — once I reach OP-16 / OP-17 I can compare rip prices in ink.
2. Coming-soon tiles name the next boxes with Box · pre-order US $ · as of.
3. Search on Sets plus the set-detail box card: one seed figure, pack facts, dated market, star/own, no qty-add chrome.

**One trade**
Oldest-first tiles (the English print run as history) vs putting the current and coming boxes first for someone who is here to rip.

**One improvement**
Under World’s The game, add one row for the latest released EN box and the next coming box, each with the same `Box · US $ · as of` line the Sets tiles already use, so a ripper who landed on `/belong` can open a box without scrolling Romance Dawn.
