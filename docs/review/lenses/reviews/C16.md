# C16 — Completionist finishing a set (plays One Piece)

**Reference first impression**
Collectr opens One Piece as Cards Only, Price high to low: SAMPLE-watermarked trophy, serial, and manga prints from about $250,000 down, each tile a large USD, a green or red %, and a +. I came to finish one set; the first glass is every chase in the game, not OP-09’s holes.

**Piecebook /belong first impression**
World asked how far I have read and left Debut arc on. Story, People, Fruits, The game, then 6 Sep / Gecko Moria — no set, no checklist, no seed $, no “you own N.” The job cannot start on this page.

**Top 5 frictions**
1. High — Reviewers land on `/belong`. Cutoff chips and wiki rooms. No box price and no card grid. I have to leave World before I can open a set.
2. High — The game’s first row is “What you own” / collection worth. “Sets in order” is the timeline (no prices). The Sets tab hits `/` and, with nothing marked, redirects to Start here. None of those doors say “the set I am finishing.”
3. High — Sets tiles are oldest EN first. Romance Dawn leads with a box seed; OP-09 sits after a stack. A tile shows card count and box price — “you own N” only after I have already marked cards. Collection is owned-only: “No owned cards yet,” not the missing list.
4. Med — OP-09’s grid defaults to Price · high to low, same chase-first stack as Collectr. Manga / SEC lead; the commons I still need are at the bottom. Sorts are name and price, not set number.
5. Med — Owned / Missing chips exist but stay hidden until I type in search, then cycle Owned → Missing. On a first open of the set I cannot see only the holes. Star / own is per cell; “You own N of M” appears only after I start marking.

**3 that work**
1. OP-09 is a full set page: one-sentence story, JP / EN dates, the box as a product with a seed price, then every print with seed $ and week move, star / own, no +.
2. Once I type, the Missing chip hides what I have marked so the grid is the holes I still need — each cell still carries a seed $ I can take to a shop.
3. Quiet paper, no SAMPLE watermark, no cart. Set tiles already print a card count, so I can see the size of the checklist I came to finish.

**One trade**
Keep World as the quiet book reviewers are sent to, versus opening a set’s checklist with the existing Missing facet on so finishing one set starts on priced holes.

**One improvement**
On a set page, show the existing Owned / Missing chip with an empty search and, once I own any card in that set, land the grid on Missing and Price · low to high so the first cells are the holes I came to buy, with seed $.
