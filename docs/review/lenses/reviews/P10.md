# P10 — Non-English-first, simple English (learn, new to One Piece)

**Reference first impression**
Bandai’s page is English marketing: “Master the Rules,” “Official Shop,” “Tutorial App.” Cookie buttons. I can see pictures of boxes. I cannot see how to play.

**Piecebook home / Start first impression**
Short words on Start. “Five sentences” is a promise I want. Learn uses long sentences with DON!!, rested, counter, blocker, Trigger. Those are new words. They are at least defined in the same sentence.

**Top 5 frictions**
1. High — Each Learn paragraph is one long sentence. Hard to parse if English is second.
2. Med — Play opens Decks. “New deck” is builder talk.
3. Med — World cutoff chips (Debut arc, Enies Lobby, Marineford) assume I know the story names.
4. Med — Outbound PDFs are more English, more pages.
5. Low — Standard / Extra in the last line is extra vocabulary.

**3 that work**
- Words like DON!! and rested are explained in the sentence, not assumed.
- The page is short. I can try again.
- No video I cannot follow without audio English.

**One trade**
Keep five sentences as five blocks vs splitting each into two short lines so a second-language reader can finish one idea at a time.

**One improvement**
Break each of the five existing sentences into two short lines, same words, no new jargon.
