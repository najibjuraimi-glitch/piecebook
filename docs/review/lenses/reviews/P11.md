# P11 — Anime fan, owns cards, never played (learn, plays One Piece)

**Reference first impression**
Bandai’s how-to-play sells me a starter and an app. I already own cards from the show. I need the table rules, not another box.

**Piecebook home / Start first impression**
World would name people I know. I came to learn. Start’s Play door mentions five sentences, then opens an empty Decks. I have cards in a tin, not in Piecebook.

**Top 5 frictions**
1. High — Play assumes I will build a deck from cards Piecebook knows I own. I have not marked them. The door is empty.
2. High — Learn does not say “take the leader from your tin, put it on the table.” It stays abstract.
3. Med — Collection is empty until I mark prints. The learn path does not tell me to mark the leader I already have.
4. Med — World can show Luffy’s fruit and debut. That does not teach an attack.
5. Low — Bandai outbound is official; I still have to leave Piecebook for a picture of a board.

**3 that work**
- Five sentences are the rules I did not get from the anime.
- I can search a name I know on Sets and see the print I own, then mark it.
- Unofficial line is honest about the show vs the game.

**One trade**
World-first for a fan vs Learn-first for a fan who already has cards and has never played.

**One improvement**
On Learn, add one line after the five sentences: mark the leader you already own (Sets search), then open Decks — using the search and own controls that already exist.
