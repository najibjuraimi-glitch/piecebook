# P14 — Returning after a year (learn, plays One Piece)

**Reference first impression**
Bandai’s beginners page looks the same as it did: video, shop, app. I already learned once. I need what changed — sets, legality — not a cookie wall.

**Piecebook home / Start first impression**
Start treats me as new. I tap Sets. New boxes exist (OP-16, OP-17, coming OP-18). Learn still teaches the same five sentences. The year-away job is “am I still legal,” which is a foot line on Learn and a Play block on cards.

**Top 5 frictions**
1. High — First visit redirect to Start. I played last year. I just have a new phone.
2. Med — Learn does not say what rotated. “Standard is the format most events use; cards from blocks that have rotated out are not legal” — no list of which blocks.
3. Med — I have to open cards one by one for Limitless Standard / Extra.
4. Med — World cutoff is manga progress, not “what I missed in the game.”
5. Low — Decks empty until I rebuild.

**3 that work**
- Sets tiles show what released while I was gone, with dates and box seeds.
- Upcoming rows count down.
- Card Play block still shows legality as Limitless publishes it.

**One trade**
A rotation table we do not have a licensed feed for vs the honest line Piecebook already prints.

**One improvement**
Skip Start when `piecebook.started.v1` is already set; for a new device, make Collect open Sets tiles, not another three-door page, so a returning player sees what released.
